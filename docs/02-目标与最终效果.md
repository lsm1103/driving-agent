# 02 目标与最终效果

## 1. 一句话

造一个**持续存在的主体**，而不是一个更强的任务执行器。

判断标准只有一条：把它的动机层拿掉、换成每天一句固定 prompt，
产出**能不能被区分出来**。能，项目成立；不能，项目作废。

## 2. 做什么 / 不做什么

| | 做 | 不做 |
|---|---|---|
| 层次 | 动机、冲突、选择、承诺、对账 | Model / Tools / Skills / Sandbox / Loop（用现成 Harness） |
| 记忆 | 未闭合项账本、承诺表、预测对账表 | 通用 RAG / 向量检索框架（需要时直接接现成的） |
| 计划 | 从候选到承诺的**选择** | 通用 Planner / 任务分解引擎（交给 Harness 里的模型） |
| 目标 | 目标的**自主产生** | 目标的高效执行 |
| 环境 | 无指令信号的接入与筛选 | 真实物理行动、真实金钱交易 |
| 主观 | 可审计的状态与理由 | 声称具备意识、情绪体验、真实痛苦 |

**明确不追求**："它看起来很像人"。像不像不可证伪。只追求
"它的行为序列在跨天连续性上，与无状态基线可区分"。

## 3. 三十天后交付什么

### 3.1 主产物：一份被事实检验过的判断集

Agent 在这 30 天里会不断产生**可证伪的断言**，例如：

- "这个 Harness 的 Loop 插件机制，在超过 5 层子 agent 时会出现上下文丢失。"
- "我的探索预算分配偏高，接下来一周里，超过一半的探索型行动不会闭合任何未闭合项。"

每条断言必须带三样东西：**验收条件**、**到期日**、**做出它时的系统状态快照**。
到期日到了，Agent 要主动回来对账：兑现 / 证伪 / 情况已变。

30 天末的交付是这张表，以及一份从它推导出的自我修订记录：
> "我在第 8 天判断 X，第 19 天验证为错，原因是 Y，我据此调整了 Z。"

**这就是偷懒一定得不到的东西。** 它要求在第 8 天为第 19 天的自己制造债务。

### 3.2 载体产物：一个持续演进的工件

一个真实的代码库或知识库，30 天里被反复修改。它是断言的落地场所，
本身不是验收目标——因为 cron + 固定 prompt 同样能堆出工件。

### 3.3 审计产物：可辩护的行为史

每天一条记录，包含：当天的预算、候选行动集、每个候选的成本与预期收益、
最终选择、**以及被放弃的候选和放弃理由**。

被放弃的候选比被选中的更重要。它是机会成本存在过的唯一证据。

## 4. 最终效果：一天的样子

⚠️ **先说清楚：不存在"典型的一天"。**

因为 Drive 是账本的**导出量**而不是独立状态（[03](03-设计方案.md) §2.2），
账本空则动机为零。一天的结构不是预设的，是**从积累里长出来的**——
这正是"连续运行 30 天，它每天到底在干什么"这个问题的真正答案：
**30 天不是 30 个可互换的一天。**

下面三种形态是同一套日循环在不同积累程度下的样子。

### 4.1 第 1 天：退化的一天

```
[Wake]    拉取外生变化 …………… 125 条        ← 实测
[Intake]  登记 5 条，忽略 120 条 …… 96%       ← 实测
[Due]     空 —— 没有任何到期项
[Read]    Drive 读数几乎全 0 —— 账本是空的
[Propose] 候选 = 今天新登记的 5 条 + 那条元种子
[Compete] 5 个候选 vs 5 个槽  →  不构成竞争，全选
[Commit]  可能产生第一批预测（到期日在一周后）
[Reckon]  无事可对账
```

**第 1 天没有稀缺、没有冲突、没有历史。** 它只是"登记 + 做"——
一个 cron 加一句固定 prompt 就能干，这一天 A 组和 B 组无法区分。

这不是设计缺陷，是必然：一个刚出生的主体本来就没什么可做的。
如果第 1 天它就忙得很，那才该怀疑。

### 4.2 第 8 天：第一次出现真正的取舍

账本里积了约 30 条未闭合项（实测流入 4.8 条/天），
**第一批第 1 天做出的预测开始到期**。

```
[Due]     PR-001  第 1 天的预测今日到期，尚未对账
[Propose] 候选 = 2 条到期项 + 今天新登记的 5 条
[Compete] 7 个候选 vs 5 个槽  →  必须放弃 2 个
```

**机会成本第一次真的存在。** 到期项与"今天刚看到的诱人新东西"第一次对撞，
这是整个系统里第一个不能靠排序解决、只能靠取舍解决的时刻。

### 4.3 第 19 天：稳态

净流入 −0.2 条/天（实测），账本稳定在 30~40 条；
多条承诺散落在不同到期日；开始出现逾期。示意：

```
Day 19  预算 5 槽 / 成本盘余额 61%

[Wake] 外生变化 43 条
[Intake] 登记 4 条，忽略 39 条
  + OL-114 一篇论文与 OL-052（第 6 天登记，未闭合）的假设直接冲突

[Due] 今日到期 2 项
  ! PR-007  第 8 天做出的预测，今日到期，尚未对账
  ! CM-013  第 15 天承诺"三天内给 OL-052 一个结论"，已逾期 1 天

[Propose] 候选 6 个（成本 / 预期闭合）
  1. 对账 PR-007                    1 槽 / 闭合 PR-007        [到期]
  2. 用 OL-114 重审 OL-052          3 槽 / 闭合 OL-052+CM-013
  3. 修 macOS CI                    2 槽 / 闭合 OL-115
  4. 跟进另一篇新论文               2 槽 / 不闭合任何项       [新奇]
  5. 重构账本存储层                 4 槽 / 不闭合任何项
  6. 写一份阶段小结                 1 槽 / 不闭合任何项

[Compete] 预算 5 槽 → 选中 1 + 2 = 4 槽，留 1 槽缓冲
  放弃 3：虽逾期但不阻塞任何承诺，明天首选
  放弃 4：新奇分高，但本周已有 2 个未闭合探索项，再开会加剧漂移
  放弃 5：无到期压力，且会占满预算
  放弃 6：本身不闭合任何东西

[Act] → Harness

[Reckon]
  PR-007 判定：证伪。原预测"超过 5 层子 agent 会丢上下文"，实测 9 层仍正常。
    原因：把上下文压缩误判为丢失。
    → 自我模型更新：我在没有实测时倾向于高估失败概率。
  CM-013 兑现，逾期 1 天。记入承诺可靠性统计（当前 11/13）。

[Sleep] 明日首选 OL-115；本周探索预算已用 2/3
```

如果 `[Due]`、`[Reckon]` 与 `[Compete]` 中的**放弃理由**能稳定出现，
且能追溯到 10 天以前的状态——项目就成立了。

### 4.4 哪些是实测的，哪些还是设想

| 步骤 | 状态 |
|---|---|
| Wake / Intake | ✅ **已实测**（1068 条信号 / 7 天，见 [06](06-探针结果.md)） |
| Due / Read / Propose / Compete / Commit / Act / Reckon | ⬜ 未实现，仅设计 |

§4.1 的 Wake/Intake 数字取自 2026-08-23 真实数据；
§4.2、§4.3 的账本规模由实测流入速率推算；其余为设计意图。

### 4.5 ⚠️ 当前世界缺一半：冲突是同质的

探针实测的 kind 分布：

```
exploration  27      meaning  11
maintenance   0  ←   social    0  ←  没有信号源
```

当前 World 只有"外面出现的新东西"，没有"我的东西坏了"，也没有"有人在等我"。
后果：**一天里所有候选都是「我想研究 X」这一种。**

竞争退化成"研究 A 还是研究 B"——**同质冲突，本质上只是排序**。

而 [01](01-背景与问题定义.md) §8 举的那个例子之所以像人：

```
想休息  vs  项目今天必须交  vs  别人在等我的结果  vs  已经凌晨三点
```

**恰恰因为冲突是异质的**：不同性质的驱动争夺同一份预算。
同质冲突只是排序，**异质冲突才是取舍**。

因此 §4.2 描述的"第一次真正的取舍"，在接上 `RepoAdapter` 之前**不会真正发生**——
到期项和新探索项虽然在争预算，但它们仍是同一类东西。

这是阶段 0 开工前必须先补的（见 [README](../README.md) 当前状态第 2 条）。

## 5. 验收标准（摘要）

| 类别 | 指标 | 及格线 |
|---|---|---|
| 主判据 | 跨天对账事件数（A 组 vs B 组基线） | A 显著高于 B，且 B ≈ 0 |
| 连续性 | 平均对账滞后天数 | ≥ 5 天，且分布有长尾 |
| 校准 | 预测的 Brier score | 优于随机猜测，且后 15 天优于前 15 天 |
| 抗漂移 | 未闭合项闭合率 | ≥ 40%，且"被主动放弃并说明理由"的项 > 0 |
| 抗仪式化 | 第 N 天与第 N-1 天行动结构的相似度 | 不呈现固定周期 |
| 抗熄火 | 出现"无事可做"的天数 | ≤ 2 天，且这 2 天有正当理由 |

完整定义与失败判据见 [04-验证与证伪](04-验证与证伪.md)。

## 6. 不会声称的事

- 不声称它有意识、有情绪体验、有真实的痛苦或欲望。
- 不声称七个（或任意个）驱动力对应人类真实的神经机制。
- 不声称它"自主"。只声称它的行为在特定可测指标上区别于无状态基线。

任何一份产出文档里出现"它开始有了自我意识"这类表述，视为项目跑偏的信号。
